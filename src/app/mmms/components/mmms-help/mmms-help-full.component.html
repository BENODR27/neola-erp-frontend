MAINTIQ · MMMS USER GUIDE

How to use the application

Follow this sequence from workspace setup to completed maintenance. Every step is connected so your organization, factory, equipment, people, work history and costs remain traceable.

Before you start

Ask your IAM administrator to grant MMMS application permission and the correct organization or factory scope. You can only see data allowed by IAM. The selector changes the working view; it never gives additional access.

01
WORKSPACE SCOPE

Select organization and factory

On every MMMS page, use the small light arrow at the top-right.

  1. Click the arrow to open the Data scope panel.
  2. Search and select an Organization.
  3. Search and select a Factory / site. Factory choices are filtered by organization.
  4. Choose “All permitted…” only when you need an organization-wide view.
  5. The page refreshes and all lists, forms, dashboard numbers and reports use the selected scope.
Always check the current organization/factory label before creating or editing a record.
02
FOUNDATION

Create the organization unit

Open Organization and define the company or business unit that owns maintenance.

  1. Click Add organization unit.
  2. Enter the unit name and unique code.
  3. Select the unit type and add owner, email, escalation contact and operating notes.
  4. Save and confirm the record appears in the list.

Use clear codes because they appear in access assignments, reports and integrations.

03
SITES

Create factories and sites

Open Factories & Sites and connect each site to its organization.

  1. Click Add factory.
  2. Search and select the parent organization from the dropdown.
  3. Enter a unique factory name and code, location and site manager.
  4. Save one record for every plant, workshop or service site.
A factory is the main scope used to separate machines, technicians, stock, work and cost data.
04
MASTER DATA

Complete related master data

Use the related pages before registering equipment. Select existing records from searchable dropdowns instead of typing names manually.

DepartmentsAssign ownershipProduction linesConnect machines to linesMachine categoriesStandardize equipmentVendorsSuppliers and contractorsCalibrationDue dates and evidenceInspectionsChecklists and findings

When a dropdown has many options, type in its search box first, then select the result.

05
ASSET REGISTER

Register and maintain machines

Open Machines and create one complete asset record for every maintainable machine.

  1. Enter machine code, asset number, name, manufacturer, model and serial number.
  2. Select category, organization, factory and production line from dropdowns.
  3. Set criticality, lifecycle condition, status, installation and warranty dates.
  4. Save the machine and verify its factory and line in the list.
  5. Use machine history to review registrations, status changes and completed work.
Keep the machine code and QR reference unique. They are used to find the asset quickly from mobile work.
06
PEOPLE

Add technicians and ownership

Open Technicians and create the maintenance team for the selected scope.

  1. Enter employee number, name, email and phone.
  2. Select factory, shift, availability and active status.
  3. Add skill categories so work can be assigned to the right person.
  4. Save and check workload and availability before assigning work orders.

Technicians, machines and work orders should belong to the same organization/factory scope whenever possible.

07
PLANNING

Plan preventive maintenance

Open Preventive Maintenance to prevent failures before they happen.

  1. Create a plan and select the machine from the machine dropdown.
  2. Define the task, frequency, next due date and responsible owner.
  3. Add inspection or calibration requirements when evidence is needed.
  4. Review upcoming due work from the dashboard and plan it before the due date.
  5. After completion, record notes, labor and parts against the resulting work order.
08
EXECUTION

Create, assign and complete work orders

Open Work Orders for planned jobs and requests from operations.

  1. Click Create work order and select the related machine.
  2. Describe the issue or task and set priority and due date.
  3. Select a technician from the searchable technician dropdown.
  4. Move the order through its workflow: Open → Assigned → In Progress → Waiting Parts when needed → Completed.
  5. Enter diagnosis, repair notes, completion notes, verification notes and labor minutes.
  6. Save only after checking the selected machine, technician and factory.
A work order is complete only when the repair is documented and the result is verified.
09
RESPONSE

Handle breakdowns and escalation

Open Breakdowns when equipment fails unexpectedly.

  1. Record the machine, start time, category, symptoms and immediate safety action.
  2. Assign or create the linked work order and set priority based on production impact.
  3. Update investigation, root cause, repair and resolution details.
  4. Escalate to the organization owner or site manager when the issue crosses the defined boundary.
  5. Close the breakdown only after the machine is tested and returned to the correct status.
10
RESOURCES

Manage spare parts and maintenance cost

Use Spare Parts and Cost Management to keep the financial and inventory trail complete.

  1. Create spare parts with category, stock quantity, reorder level, supplier and unit cost.
  2. When a work order uses a part, record the part and quantity in the work details.
  3. Record labor minutes and contractor costs against the correct machine and work order.
  4. Review low stock, part cost, labor cost and total cost by factory.
  5. Use Vendors to maintain supplier records centrally.
11
FIELD WORK

Use QR access and mobile maintenance

Open QR Access to identify equipment quickly and Mobile Maintenance for technician execution.

  1. Print or attach the machine’s QR reference at the asset.
  2. Scan the code to find machine details, open work orders and breakdown history.
  3. Use the mobile task list to see assigned jobs, priority and synchronization status.
  4. Update notes and completion information while at the machine.
  5. Return to the main work order to verify the final status and notes were saved.
12
CONTROL AND IMPROVEMENT

Review reports and production impact

Use Reports and Production Impact to make decisions.

  1. Select the organization and factory scope before reviewing numbers.
  2. Check machine count, open work, active breakdowns, downtime and maintenance cost.
  3. Review overdue preventive work and recurring root causes.
  4. Compare production impact, units at risk and recovery status.
  5. Use findings to adjust preventive frequency, technician capacity, spare stock and escalation rules.
Reports are meaningful only when machines, work orders, labor, parts and completion notes are recorded consistently.
QUICK TROUBLESHOOTING

If something is missing

No organization or factory appears

Ask the IAM administrator to assign MMMS access and organization/factory scope, then sign in again.

A dropdown is empty

Confirm the related master data was created in the same selected organization/factory and refresh the page.

Data changed unexpectedly

Check the top-right scope panel. Switching factory changes every list and report to that factory.

You cannot save a record

Check required fields, selected relationships and that the record belongs to your permitted scope.
